# Manara — getmanara.online

Website for Manara, a freelance consulting collective. "Manara" (منارة) means *lighthouse* in Arabic.

- Design generated with Lovable, packaged as a static Vite + React + Tailwind site.
- `main` holds the source; `gh-pages` holds the built site served by GitHub Pages at https://getmanara.online.

## Develop
```
npm install
npm run dev
npm run build   # outputs to dist/
```
