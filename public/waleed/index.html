Cybersecurity MLCode

NetSentry

ML intrusion detection that sorts network connections into normal or malicious, and names the attack family.

  • Identifies DoS, Probe, R2L and U2R attacks.
  • Holds up on attacks it has never seen: most of the 17 attack types missing from training are still caught.
  • Evaluated on the official KDDTest+ split.
Biggest lesson: the textbook 0.5 cut-off misses a lot. Tuning the alert threshold for a target false-alarm rate changes everything.

AI agentsCode ↗

OpsAgent

An AI on-call agent that's safe near production, built around the parts that make agents trustworthy.

  • Its own MCP server, with a risk level on every tool.
  • Human approval before any risky action, and the agent reads why you said no. Deny a restart in the demo and it goes and finds the bad deploy instead.
  • Crash recovery that never repeats a change it can't prove didn't happen.
  • Full tracing of every model call, tool call and approval.
PythonMCPAI agentsTracing

Demo agent scenes use a scripted model (no API key) driving the real agent loop, MCP server and recovery code.
